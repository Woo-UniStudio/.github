# WooStudio

**Woo** 是一个面向德国大学生的校园平台，目前从 TUM 的课程与校园生活开始。

我们希望把课程信息、课表规划、学习支持和同学之间的交流放在一起，让日常学习更方便。

**Woo** is a campus platform for university students in Germany, starting with courses and campus life at TUM.

We bring course information, timetable planning, learning support, and student discussions together in one place.
